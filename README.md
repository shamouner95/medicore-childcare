🏥 Medicore — Climate-Resilient Pediatric Care

Medicore is an AI-powered pediatric healthcare platform built with Flutter, Firebase, and Gemini AI to support children in climate-vulnerable and low-connectivity communities.

The platform provides:

🧠 AI-powered smart triage and hospital matching
🆔 Offline QR-based child health records
📈 Predictive surge forecasting for climate-linked diseases
🗺️ Real-time outbreak and disaster reporting

Medicore helps hospitals prepare for malaria, cholera, and respiratory outbreaks before they escalate while ensuring continuous healthcare access during internet outages or emergencies.

🛠️ Tech Stack

Flutter • Firebase • Gemini AI • Google Maps API
